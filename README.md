# 🧪 DiluCalc - Laboratory Standard Solution & Dilution Calculator

DiluCalc is a standalone desktop utility designed for analytical chemistry laboratories to calculate precise standard solution preparation, mass weighing (with tare/beaker options), and matrix acid dilutions (ppm, ppb, ppt levels).

---

## ✨ Features
* **Precise Calculations:** Dynamic decimal and significant figure scaling designed for ultra-trace analysis (down to ppt and pg levels).
* **Matrix Acid Support:** Automatically calculates stock acid volumes based on custom purity and density values.
* **Customizable Library:** Easily add, view, or remove elements, acids, and solutes directly through the user interface (saved locally in `dilucalc_library.json`).
* **Multi-Format Export:** Export preparation recipes instantly as Word (`.docx`), Excel (`.xlsx`), or Image (`.png`) cards.
* **Standalone Portable App:** Runs without requiring a Python installation or active web server.

---

## 📖 How to Use
1. Run `DiluCalc.exe`.
2. Select your target element, concentration unit, and final volume from the **Parameters** panel.
3. Configure matrix acids or tare weighing options if needed.
4. View real-time instructions and required quantities on the right panel.
5. Use the top menu (`Data -> See Library`) to manage custom chemical inventories.
